# 🐾 Paws & Strolls – Dog Walking Website Template

A modern, interactive single-page website template designed for dog walking businesses. Built with pure HTML, CSS, and JavaScript — no frameworks or dependencies required.

## Preview

A premium, fun-yet-professional design featuring glass-morphism effects, smooth animations, and a fully responsive layout.

## Features

- **Fully Responsive** — Looks great on desktop, tablet, and mobile
- **Interactive Animations** — Scroll reveals, 3D tilt cards, magnetic buttons, parallax orbs, and ambient floating particles
- **Mosaic Gallery** — Asymmetric image grid with elegant hover overlays
- **Testimonials Carousel** — Auto-playing slider with swipe support and dot navigation
- **Animated Counters** — Stats that count up when scrolled into view
- **Contact Form** — Validated form with success modal
- **GPS & Photo Update Branding** — Highlights key service differentiators
- **Dark/Light Section Contrast** — Alternating backgrounds for visual depth
- **No Dependencies** — Pure HTML, CSS, and vanilla JavaScript

## Tech Stack

| Layer   | Technology                  |
| ------- | --------------------------- |
| HTML    | Semantic HTML5              |
| CSS     | Custom properties, Grid, Flexbox, Glass-morphism, Keyframe animations |
| JS      | Vanilla ES6+ (IntersectionObserver, DOM manipulation) |
| Fonts   | [Sora](https://fonts.google.com/specimen/Sora) & [DM Sans](https://fonts.google.com/specimen/DM+Sans) via Google Fonts |
| Images  | [Unsplash](https://unsplash.com) (free, no API key needed) |

## Getting Started

1. **Clone the repo**
   ```bash
   git clone https://github.com/your-username/DogWalkingTemplate.git
   ```
2. **Open in browser**
   ```
   Open index.html in any modern browser — no build step needed.
   ```
3. **Customise**
   - Update business name, contact details, and services in `index.html`
   - Adjust colours via CSS custom properties in `:root` at the top of `styles.css`
   - Swap Unsplash image URLs for your own photos

## Sections

1. **Navbar** — Sticky with blur backdrop, mobile hamburger menu
2. **Hero** — Gradient orbs, floating info cards, social proof
3. **Services** — 4-card grid with tilt effect (Solo Stroll, Pack Walk, Puppy Drop-In, Overnight Stay)
4. **About** — Image + features grid with experience badge
5. **Stats** — Animated counters on dark background
6. **Testimonials** — Carousel with auto-play and swipe
7. **Gallery** — Mosaic layout with hover reveal overlays
8. **Contact** — Form with validation + success modal
9. **Footer** — Links, contact info, branding

## Browser Support

Works in all modern browsers (Chrome, Firefox, Safari, Edge). Uses `IntersectionObserver`, `backdrop-filter`, CSS Grid, and ES6+ features.
